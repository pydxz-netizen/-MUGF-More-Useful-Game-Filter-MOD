# -MUGF-More-Useful-Game-Filter-MOD
This is a tool mainly for filtering games on steam, everyone can simply use it. It has clean GUI and easy operating methods, you know what to do once you open it. What's more, if you are good at python, you can get your own information list and use this MOD to show the statistics.

How to use?
Look for "main.py" in the folder, run it, then it'll work on browser.

Detailed function:
1. Filter
2. The games meet the need will be shown in the axis. X: price, Y: favorable rate, Color: Rating amount
3. Choose the games you liked by clicking the dots, or by one click of the shortcut key below.
4. Chosen games will be shown in the list and bar graph below. Decide the final games you are favor of with the help of them, then click the name of game to directly jump to the steam store.

In the folder I've stuffed lots of xlsx, md and py. Only useful xlsx is the "tot" one, in which the statistics would be shown on browser. Because that the project is done with the help of AI, md files detailedly recorded most of the prompts, which might be useful for you.
All of the py files can be changed as you like, in order to realize various function of this project.
